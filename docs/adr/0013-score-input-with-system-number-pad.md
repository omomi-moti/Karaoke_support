# 0013. 点数は標準テンキーで右詰めに入力し、入力欄は見えなくする

- 2026-10-14 ／ 承認
- 背景：点数を小数第3位まで入れるには、スライダーでは細かく合わせられない。採点画面の数字をそのまま打ち込めるようにしたい（[0012](0012-score-three-decimals-optional.md)）

## 比較した案
- A. スライダーのまま刻みを細かくする
- B. 画面内に自前のテンキーを置き、右詰めで入力する
- C. 標準テンキー（`.numberPad`）の入力欄を表示し、打つたびに中身を `92.345` の形に書き換える
- D. 標準テンキーの入力欄は見えなくして数字だけ（`92345`）を持ち、表示は別のテキストで `92.345` に整える

## トレードオフ
- A は 0.001 刻みを指で合わせられない
- B は見た目を自由に作れるが、テンキーが常に画面を占め、ほかの入力欄が下に押し出される。iPhone の標準と操作感が違う
- C は入力欄が見えて分かりやすいが、打つたびに中身を書き換えるので、速く打つと数字が抜ける（シミュレータで `0.092` に 3・4・5 と続けて打つと `9.235` になった）
- D は書き換えが起きないので数字が抜けないが、入力欄が見えないので、カーソルの代わりを自分で出す必要がある。途中の桁だけを直すことはできない（末尾から消して打ち直す）

## 選んだ理由
- D。速く打っても数字が抜けないことを優先した。標準テンキーなので操作に迷わない
- 右詰め（打った数字が右から押し出される）にして、小数点を打たなくて済むようにした。写真から読み取った点数を初期値に入れても、同じ操作で直せる
- 入力中は数字の右端にカーソルを点滅させる。テンキーには閉じるボタンがないので、点数を入力中のときだけキーボードの上に「完了」を出す

## 見直す条件
- 途中の桁だけを直したいという要望が出たとき
- 写真からの読み取りで、手で打つ場面がほとんどなくなったとき
