# 0019. 記録の編集中は、帯・「更新する」・読むだけの曲名で新規と見分けられるようにする

- 2026-10-16 ／ 承認
- 背景：新規と編集で同じ記録シートを使っており、違いは小さな見出し（「記録を追加」／「記録を編集」）と歌唱日時の欄くらいだった。どの記録を直しているのかも出ていなかった。編集では曲を変えられないのに、曲名は押せないだけの入力欄で表示されていて、触れそうに見えた

## 比較した案
- A. 一番上に、元の歌唱日時を添えた「〜の記録を編集中」の帯を出す
- B. 保存ボタンを「更新する」（チェックマーク）にする
- C. 曲名を入力欄ではなく、鍵アイコンと「曲は変更できません」を添えた文字で出す
- D. 編集中は保存ボタンなど記録シート全体の色を、履歴の「編集」スワイプと同じ青にする

## トレードオフ
- A は編集中であることと、どの記録かが一目で分かる。画面の縦が帯の分だけ伸びる。帯を入力カードと同じ見た目にすると、見出しの 1 枚として読み流される
- B は押した結果（今の記録を書き換える）が分かる。新規と編集でボタンの文言が変わる
- C は触れない場所を触れそうに見せなくなる。新規と編集で曲名の見た目が変わる
- D は一番伝わりやすいが、記録シートの色が新規と編集で変わり、統一感が下がる

## 選んだ理由
- A・B・C。A と B で編集中であることは十分伝わるので、色まで変える D は外した
- 帯の日時は編集を始める前の歌唱日時にし、日時欄を変えても帯は変えない（変えると、どの記録を直しているか分からなくなる）。表記は履歴の行と同じにして、開いた行と見比べられるようにした
- 帯は最初、入力カードと同じ半透明の見た目にしたが、見出しのように読み流されて編集中だと気づきにくかった。そこで帯だけ見た目を変えた
  - 色付きの丸に鉛筆アイコンを入れ、「編集中」を太字で先頭に置き、日時はその下に小さく出す
  - 色は青（`AppColor.editAccent`）にした。最初に試したピンクは点数・更新ボタン・Shout の気分と同じ色で、Shout の記録だと帯がほかのピンクに埋もれた。青は履歴の「編集」スワイプと同じ色なので、押したボタンと開いた画面がつながって見える
  - D（画面全体を青にする）とは違い、色を変えるのは帯だけなので、記録シートの統一感は保てる

## 見直す条件
- 帯や「更新する」でも編集中だと気づかれず、新規と間違えて保存される場面があったとき（D を足す、または変えた欄に印を付ける）
- 記録を 1 件ずつ見る画面（#104）から編集を開くようになり、どの記録かを帯で示す必要がなくなったとき
