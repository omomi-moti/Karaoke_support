# 0014. 点数は丸めず小数第3位まで表示し、平均は切り捨てる

- 2026-10-14 ／ 承認
- 背景：小数第3位まで入力できるようにした（[0012](0012-score-three-decimals-optional.md)）が、表示は小数第1位に丸めていた。しかも画面によって丸め方が違い、同じ 92.350 が履歴では 92.4、マイアンセムでは 92.3 と表示されていた（FormatStyle と `String(format:)` の違い）

## 比較した案
- A. 小数第1位に四捨五入して表示する
- B. 小数第1位に切り捨てて表示する
- C. 丸めず小数第3位まで表示する

## トレードオフ
- A・B は一覧がすっきりするが、入力した値と表示が食い違う。A は 99.95 が「100.0」に見える
- C は数字が長くなり、狭い場所（今月の平均スコアのチップ）では縮小が必要になる

## 選んだ理由
- C。採点画面と同じ桁で見比べられることを優先した。入力が小数第3位までなので、丸めの規則を決めなくて済む
- 表示は `ScoreFormat` にまとめ、どの画面でも同じ形にする。保存した値の `Double` の誤差（92.34499…）は、表示する前に千分の一点に寄せて消す
- 平均だけは割り算で桁が増えるので、小数第3位で切り捨てる（実際より高く見せない。99.9999 を 100.000 と見せない）
- 前回比は符号付きで小数第3位まで出す
- 点数なしは「—」

## 見直す条件
- 一覧が長い数字で読みにくいと感じるようになったとき（一覧だけ桁を減らすなど）
