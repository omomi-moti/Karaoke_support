# 0011. 手入力の曲は曲名＋歌手名で区別し、新しい曲では歌手名を必須にする

- 2026-10-14 ／ 提案
- 背景：手入力の曲は曲名（`userEnteredName`）だけで同じ曲かを判定しているため、別のアーティストの同名曲（「Lemon」「糸」など）が 1 曲として集計される（#97）

## 比較した案
- A. 今のまま曲名だけで区別する
- B. 歌手名を足し、入力は任意にする
- C. 歌手名を足し、新しく曲を作るときは必須にする（既存の曲を候補から選んだときは自動で入る）

## トレードオフ
- A は入力が楽だが、同名曲が混ざる
- B は入力の手間は少ないが、「a / A さん」「a / B さん」「a / 歌手名なし」の 3 つができ、歌手名なしの「a」がどちらの曲か判断できない
- C は初めて歌う曲で入力が 1 つ増える。既存のデータは歌手名がないので、データの型は任意（`String?`）のままにし、必須チェックは記録シートで行う必要がある

## 選んだ理由
- C。B では同名曲が混ざる問題が「歌手名なし」の形で残る。歌手名が必要なのは初めて歌う曲だけで、2 回目以降は候補を選べば自動で入る。歌手名はカラオケの採点画面に出ているので、今後、写真から曲名と歌手名を読み取れるようにすれば入力の手間も減らせる
- 歌手名なしの既存の曲と同じ曲名を歌手名付きで記録したときは、既存の曲に歌手名を補って同じ曲として扱う
- Spotify 由来の曲は Spotify の曲 ID で区別するので、歌手名は不要（歌手名も永続化しない。[0002](0002-no-persisting-spotify-metadata.md)）

## 見直す条件
- 歌手名の入力が記録の手間として重いと分かったとき（写真の読み取りで自動入力できない場合など）
