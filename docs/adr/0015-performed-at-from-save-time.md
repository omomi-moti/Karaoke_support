# 0015. 新規記録の歌唱日時は保存した時刻にし、日時欄は編集のときだけ出す

- 2026-10-14 ／ 承認
- 背景：記録シートに歌唱日時の入力欄があったが、記録は歌った直後につけることがほとんどで、日時を変えることはまれだった。標準の DatePicker は端末の言語に従って英語で出ることもあり、シートの中で浮いていた

## 比較した案
- A. 日時欄をそのまま残し、見た目だけ整える
- B. 日時欄をなくし、新規も編集も日時を変えられないようにする
- C. 新規記録では日時欄を出さず保存した時刻にし、履歴からの編集のときだけ日時欄を出す

## トレードオフ
- A は後からまとめて記録するときも日時を合わせられるが、ほとんどの記録で使わない欄が残る
- B は一番すっきりするが、日時を間違えたときに直せない
- C は新規の入力が 1 つ減るが、カラオケの後でまとめて記録すると、記録した時刻が歌唱日時になる（編集で直す必要がある）

## 選んだ理由
- C。ほとんどの記録で入力の手間が減り、間違えたときは編集から直せる
- 新規の日時は、シートを開いた時刻ではなく保存した時刻にする
- 後からまとめて記録するケースは、今後、写真から点数を読み取るときに撮影日時を使えば自然に解決できる見込み

## 見直す条件
- 後からまとめて記録することが多く、毎回編集で日時を直す手間が目立つとき
- 写真から読み取るようになり、撮影日時を使えるようになったとき
