# 0044. Practice は「練習中の曲」と「歌い切れなかった曲」に分けて出す

- 2026-10-27 ／ 承認
- 背景：選曲MVP のスプリント 6（#131）。[0043](0043-practice-challenges.md) で、最新の記録が Practice の曲と、最新の記録で歌い切れなかった曲を「挑戦中の曲」として 1 つのリストにまとめ、日数が長い順に混ぜて並べた。実装して見たところ、目的の違う 2 種類の曲が混ざり、練習したい曲を選びにくかった。この ADR は 0043 の 1（Practice のチップの中身）・3（Practice で保存したときの保存直後のシート）・4（並び順）を置き換える。挑戦中の決め方（0043 の 2）と、Practice で歌い切れなかった曲を「歌い切れず」とすること（0043 の 5）は変えない

## 比較した案

1. Practice のチップの中身
- A. 「練習中の曲」（最新の記録が Practice で歌い切れた曲）と「歌い切れなかった曲」（最新の記録で歌い切れなかった曲。気分は問わない）の 2 つのセクションに分ける
- B. 0043 のまま、「挑戦中の曲」の 1 つのリストに混ぜる

2. 「練習中の曲」の決め方
- A. 最新の記録が Practice の曲（0043 と同じ）
- B. 一度でも Practice で歌った曲（ほかの気分で歌い切っても残る）

3. 「歌い切れなかった曲」を出す場所
- A. Practice のチップだけ（0043 と同じ）
- B. そのとき歌った気分のチップ

4. Practice で保存したときの保存直後のシート
- A. 練習中の曲から 2 曲を出し、足りなければ歌い切れなかった曲で埋める
- B. 0043 のまま、挑戦中の曲を混ぜた順で 2 曲

## トレードオフ

- 1-A は、点数を上げたい曲と、まず歌い切りたい曲を分けて選べる。Practice のチップのセクションが 2 つになる
- 1-B は 1 つのリストで済むが、目的の違う曲が日数順に混ざり、練習したい曲を探しにくい
- 2-A は「最新の記録で決める」という決まりがほかと同じで、1 つの曲が必ずどこか 1 か所に出る。ほかの気分で歌うと Practice から外れる
- 2-B は練習を続けたい曲が残りやすいが、Practice の曲が Shout・Emo の候補にも出るか、どちらに出すかの決まりが要る
- 3-A は、歌い切れなかった曲が気分で選ぶ候補に混ざらない。Shout や Emo のチップでは見えない
- 3-B は気分のまま思い出せるが、気分のチップの中に、すぐには歌いにくい曲が混ざる
- 4-A は、Practice を選んで保存した直後に、練習の続きの曲が先に見える。歌い切れなかった曲は、練習中の曲が少ないときだけ出る
- 4-B は日数の長い曲から出るが、練習中の曲と歌い切れなかった曲のどちらが出るかが入力しだいになる

## 選んだ理由

- 1 は A。歌い切れた曲と歌い切れなかった曲は、分けて練習しないと意味がない。1 つに混ぜると、Practice の曲が選曲されにくい。歌い切れる＝練習がいらない、ということではないので、歌い切れた Practice の曲も「練習中の曲」として残す
- 2 は A。最新の記録で決める決まりは変えない
- 3 は A。歌い切れなかった曲は Practice のチップにだけ出す
- 4 は A。Practice で保存したときは、練習の続きの曲を先に見せる

## 見直す条件

- ほかの気分で歌い切った曲も、Practice に残してほしいと言われたとき（2 を B にする）
- 歌い切れなかった曲を、Shout や Emo のチップでも見たいと言われたとき（3 を B にする）
