# 0043. Practice のチップは「挑戦中の曲」だけを出し、挑戦中の曲はほかの候補に出さない

- 2026-10-27 ／ 承認（1・3・4 は置き換え済み → [0044](0044-split-practice-into-practicing-and-unfinished.md)）
- 背景：選曲MVP のスプリント 6（#131）。元の仕様では、最新の記録の気分が Practice の曲（点数アップ）と、最新の記録で歌い切れなかった曲（歌い切れず）を「挑戦中」として、選曲画面の Practice のチップにだけ出す。今は、Practice のチップは「最新の気分が Practice の曲」を「また歌いたい」と「今の気分に合う曲」に出していて（[0039](0039-selection-screen-sections.md) の 2）、歌い切れなかった曲はどこの候補にも出していない（[0042](0042-exclude-unfinished-songs-from-suggestions.md) の 3）。この ADR は 0039 の 2 と 0042 の 3 を置き換える

## 比較した案

1. Practice のチップの中身
- A. 「挑戦中の曲」の 1 セクションだけにする（元の仕様のモックどおり）
- B. 「挑戦中の曲」と「また歌いたい」を並べる

2. 挑戦中の決め方と、ほかの候補との関係
- A. 挑戦中を「最新の記録の気分が Practice、または最新の記録で歌い切れなかった」の 1 つの判定にし、挑戦中の曲は Practice にだけ出す。Shout・Emo の候補（また歌いたいも含む）からは外す
- B. 挑戦中の曲も、Shout・Emo の候補に出す

3. Practice で保存したときの保存直後のシート
- A. 挑戦中の曲の上位 2 曲を出す
- B. 今のまま（最新の気分が Practice で、歌い切れた曲）

4. 挑戦中の曲の並び順
- A. 最後に歌ってからの日数が長い順。同じなら最高点が低い順（点数がない曲を一番低いとする）
- B. 歌い切れなかった曲を先にし、そのあと点数アップの曲

5. 最新の記録が Practice で、しかも歌い切れなかった曲
- A. 「歌い切れず」として出す
- B. 「点数アップ」として出す

## トレードオフ

- 1-A は Practice の意味が「練習中の曲を見る場所」とはっきりする。Practice のチップでは、ハート付きの曲の一覧が見えなくなる
- 1-B は Practice でもハート付きの曲が見えるが、ほかの気分と同じ形になり、Practice だけ目的が違うことが伝わりにくい
- 2-A は、1 つの曲が最新の記録で必ずどこか 1 か所に決まる（最新の気分のチップか、挑戦中か）。元の仕様の「Practice 以外の気分で歌い切れたら外れる」も、この判定から自然に出る。最新の気分が Practice のハート付きの曲は、Shout・Emo の「また歌いたい」に出なくなる
- 2-B は「また歌いたい」が広く見えるが、練習中や歌い切れなかった曲が、気分で選ぶ候補に混ざる
- 3-A は「もっと見る」で開く Practice のチップと中身がそろう。保存直後のシートで、Practice のときだけ並べ方と理由の行が変わる
- 3-B は保存直後のシートに手を入れずに済むが、Practice で保存したときに、選曲画面の Practice のチップと中身が食い違う
- 4-A は 2 種類の挑戦中の曲を混ぜて、久しぶりの曲から思い出せる。点数が低い曲ほど練習が要るので先に出る
- 4-B は歌い切れなかった曲を見落としにくいが、点数アップの曲が下に沈む
- 5-A は「歌い切れなかった」ことと、そのとき書いたメモが見える。5-B は Practice で歌ったことは分かるが、歌い切れなかったことが見えない

## 選んだ理由

- 1 は A。Practice は挑戦中の曲を見る場所にする
- 2 は A。挑戦中を 1 つの判定にまとめると、1 つの曲は最新の記録で必ずどこか 1 か所に出る。歌い切れなかった曲を気分に関係なく挑戦中に出し、そのとき歌った気分は理由の行で分かればよい
- 3 は A。「もっと見る」で開く Practice のチップと中身をそろえる
- 4 は A。久しぶりの曲から思い出せるようにするため
- 5 は A。歌い切れなかったことの方が、次に歌うときに知りたい情報のため

## 見直す条件

- Practice のチップで、ハート付きの曲も見たいと言われたとき（1 を B にする）
- 挑戦中の曲が多くなり、点数アップの曲が下に沈んで見つからないとき（4 を見直す）
