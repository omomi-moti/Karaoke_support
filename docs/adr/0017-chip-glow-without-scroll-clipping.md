# 0017. 選んだチップの光は、ScrollView の切り取りを止めて見せる

- 2026-10-15 ／ 承認
- 背景：履歴の絞り込みチップに記録シートと同じ光を付けた（[0016](0016-unify-intent-colors-and-icons.md)）が、チップを並べた横スクロールの ScrollView が枠の外を切り取るため、光が上下で切れて四角く見えた

## 比較した案
- A. ScrollView に `.scrollClipDisabled()` を付け、枠の外にも描けるようにする
- B. ScrollView の中に余白を足し、外側で同じだけ詰める
- C. チップには光を付けない（塗りと枠だけ）
- D. 光を小さくする

## トレードオフ
- A は 1 行で済み、光がどこも切れない。ただし文字を大きくしてチップがスクロールするとき、チップが画面の左右の余白を越えて画面の端まで流れる
- B ははみ出しが起きないが、余白を打ち消すコードが要る。左端のチップの光を切らないには左右にも余白が要り、チップの左端が一覧のカードとずれる
- C は切り取りの問題がなくなるが、記録シートと見た目をそろえる方針（[0016](0016-unify-intent-colors-and-icons.md)）から外れる
- D は切り取りが目立ちにくくなるだけで、なくならない

## 選んだ理由
- A。光が切れず、チップの位置も変わらない。大きな文字サイズで画面の端まで流れる見た目は、シミュレータで見て許容できると判断した
- あわせて、チップの見た目を次のようにした
  - 枠は `strokeBorder` で内側に描き、選択を切り替えてもチップの外形が変わらないようにする（`stroke` は線の半分が外にはみ出す）
  - 「すべて」の枠は半透明にし、ライトモードで黒い太線にならないようにする

## 見直す条件
- チップが余白の位置できっちり切れていてほしいと感じたら、B に替える
- チップの上下にほかの要素が近づき、光が重なるようになったとき
