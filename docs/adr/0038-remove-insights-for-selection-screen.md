# 0038. 選曲タブの振り返り（タイムマシン・マイアンセム・今月の統計）を消し、選曲タブを選曲画面にする

- 2026-10-27 ／ 承認
- 背景：選曲MVP のスプリント 4（#126）。「もっと見る」で開く選曲画面を、今の「選曲」タブに置く。今の選曲タブには、振り返りの 3 つ（タイムマシン：直近 1 ヶ月によく歌った曲、感情別マイ・アンセム：気分ごとの回数と点数のランキング、今月の統計：記録の数と平均スコア）だけが並んでいる。親 Issue（#114）のバックログでは、選曲画面を作る前に、この 3 つを履歴へ移すとしていた

## 比較した案

- A. 3 つとも消す
- B. 履歴タブへ移す（一覧の上、右上のボタンから開く画面、上の切り替えのどれか）
- C. 選曲画面の下に残す

## トレードオフ

- A はアプリの役割が「記録する → 履歴・曲詳細で振り返る → 選曲画面で次を選ぶ」にまとまり、画面と集計のコードが減る。マイアンセムは、選曲画面の「気分のチップ → 今の気分に合う曲」と役割が重なる。タイムマシンの「最近よく歌った曲」は、履歴の一覧でおおよそ分かる。今月の統計は重ならないが、なくなる。消したコードは git に残るので、要るときは戻せる
- B は 3 つとも残るが、履歴の一覧が下に押されるか、入口が 1 段深くなる。マイアンセムと選曲画面の重なりは残り、「気分で曲を見る」場所が 2 つになる
- C は移す手間がないが、選曲画面に振り返りが混ざる。仕様書の「今回やらないこと」（選曲画面での振り返り系の入口）とも合わない

## 選んだ理由
- A。今の実装は、ユーザーの嗜好性にフォーカスしきれていなかったと判断した
- タイムマシンと感情別マイ・アンセムは、履歴を集計して出しているだけで、ユーザーの記録を本当には活かしきれていなかった。方向性は悪くないが少しずれていたと判断したため、この選曲ロジックを消すことにした
- 実際に使ってもらったとき、選曲タブから曲を選ぶことは少なかった。気分（テンション）と点数だけではユーザーに寄り添えていないと判断し、保存直後の提案・ハート・選曲画面の今の設計にし直している

## 見直す条件

- 使っている人から、タイムマシンや今月の統計を戻してほしいと言われたとき
- 選曲画面の「今の気分に合う曲」とは別に、回数や点数のランキングを見たくなったとき
