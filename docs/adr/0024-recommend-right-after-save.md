# 0024. 次の 1 曲の提案は、記録を保存した直後にシートで出す

- 2026-10-24 ／ 承認
- 背景：ひとカラの後半に、前に歌って良かった曲を思い出せず次の 1 曲が決まらない（#114）。過去の曲を見せる場所とタイミングを決める。次の曲を選ぶのは今の曲を記録した直後で、そのとき直前の気分も分かっている

## 比較した案
- A. 保存した直後にシートで出す（上位 2 曲、「あとで」で閉じる）
- B. 選曲タブを開いたときだけ出す
- C. 保存した後の履歴の画面の上に、小さく出す（バナーなど）

## トレードオフ
- A は提案が要る瞬間に必ず目に入り、保存した記録の気分をそのまま使える。代わりに、記録だけしたい人には保存のたびに 1 枚増える
- B は保存の流れを変えずに済むが、選曲タブを開かないと見えず、後半に迷ったときに思い出してもらえない
- C は邪魔になりにくいが、気づかれにくく、候補を 2 曲並べる場所が取りにくい

## 選んだ理由
- A。検証したい仮説（保存の直後に過去の曲を見せれば次の 1 曲が決まる）を、そのまま試せる。「あとで」で閉じても記録は保存済みのまま
- 次の場合はシートを出さず、今までどおり履歴へ移るだけにする
  - 候補が 0 件のとき：中身のないシートで保存の流れを止めないため（記録が少ない最初のうちは必ず起きる）
  - 編集して更新したとき：次の曲を選ぶ場面ではないため
  - 候補の読み込みに失敗したとき：記録はもう保存できているので、エラーは出さない
- スプリント 1（#115）では「もっと見る」（選曲画面）は出さない。選曲画面ができたら足す

## 見直す条件
- 保存直後のシートが、ほとんど「あとで」で閉じられるとき
- ひとカラの後半で、候補が 0 件でシートが出ないことが多いとき（同じ気分の曲を今日もう歌い切った、など）。そのときは、別の気分の曲で埋めるか、空でもシートを出すかを検討する
