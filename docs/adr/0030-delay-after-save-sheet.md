# 0030. 保存直後のシートは、保存してから 1 秒たってから出す

- 2026-10-25 ／ 置き換え済み（→ [0032](0032-move-to-history-after-dismiss.md)）
- 背景：[0025](0025-switch-root-sheet-after-save.md) では、記録シートが閉じ終わった瞬間（保存から約 0.3 秒）に保存直後のシートを出していた。実機で使うと、履歴に記録が増えたのを見る間もなく次のシートが出て、急に感じた。0025 の「見直す条件」に挙げていた場合にあたる

## 比較した案
- A. 今のまま、閉じ終わった瞬間に出す
- B. 保存した時刻から一定の時間がたつまで待ってから出す
- C. 記録シートを閉じずに、同じシートの中身を「保存しました＋候補」に差し替える（0025 の B）

## トレードオフ
- A は待たせないが、記録が増えたことが目に入らず、急に感じる
- B は変えるのが `handleSaved` の数行で済み、シートの切り替えの仕組み（閉じ終わるのを待つ、二度押し）はそのまま使える。待っている間に履歴の行から曲詳細へ移ると、曲詳細の上にシートが出る
- C は閉じて開く動きがなくなるが、履歴に記録が増えたことは見えなくなる。記録シートに別の画面の状態を持ち込むことになり、変える量も多い

## 選んだ理由
- B。待ち時間は 1 秒にした（記録シートが閉じ終わってから約 0.7 秒）。感じ方の問題なので、定数（`RootView.afterSaveSheetDelay`）1 つで変えられるようにした
- 待ち時間の起点は「保存した時刻」にした。候補の読み込みにかかった時間も待ち時間に含めるので、読み込みが遅いときにさらに待たせることはない
- 待っている間に＋や編集で別のシートを開いた・開こうとしているときは、0025 と同じく保存直後のシートは出さない

## 見直す条件
- 実機で使って、まだ急に感じる、または待たされると感じるとき（定数を変える）
- 待っている間に曲詳細へ移って、その上にシートが出ることが気になるとき
