GitHub のアカウントがある方は、[Issues](https://github.com/omomi-moti/Karaoke_support/issues/new) からも送れます。Issues は**誰でも読める公開の場所**です。曲名や点数、メモなど、ご自身の記録の内容は書かないでください。

## よくある質問

### 記録を消すには？

曲の詳細の画面から、記録を 1 件ずつ削除できます。すべて消したいときは、アプリを削除してください。アプリの中の記録もすべて消えます。

### 記録はどこに保存されますか？

ユーザーの iPhone の中だけです。外部のサーバーには送信されません。くわしくは[プライバシーポリシー]({{ '/privacy/' | relative_url }})を見てください。

### 機種変更で記録を引き継げますか？

アプリの中に、記録を書き出したり読み込んだりする機能はありません。iPhone のバックアップから新しい iPhone へ復元したときは、バックアップにアプリのデータが含まれていれば、記録も戻ります。

### ネットワークがなくても使えますか？

使えます。このアプリは、記録も提案も、すべて iPhone の中で動きます。
